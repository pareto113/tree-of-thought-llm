## 비용 구조 분석

### Game24 ToT가 가장 비싼 이유

```
1개 퍼즐 기준:
  4 steps × (propose 1회 + value 3회 × 최대 5개 후보)
  → 최대 64회 API 호출
```

- `prompt_tokens`이 `completion_tokens`의 **2.5배** — few-shot 예시가 길어 입력 비용이 큼
- `value_cache`로 중복 호출을 방지하지만 첫 실행 시엔 전액 발생

### Crosswords DFS가 구조적으로 가장 비싼 이유

- 10개 단어(가로5 + 세로5) × 백트래킹 탐색
- `propose_prompt`가 전체 보드 상태를 포함해 프롬프트가 매우 길다 (평균 ~2,300 chars)
- 가지치기(pruning) 없으면 API 호출이 기하급수적으로 증가
