# 적용 실험으로 프레임, 재현 실험 아님

GPT-4o mini는 원 논문이 사용한 GPT-4와 다른 모델이므로 논문 수치를 그대로 재현하는 것은 목표가 아니다. 대신 GPT-4o mini로 IO / CoT / ToT 세 방법을 동일 조건에서 실행해 방법론 자체의 효과(IO < CoT < ToT)를 검증하고, 논문 GPT-4 결과와 비교 분석하는 구조를 택한다.

## Considered Options

- **A. GPT-4 사용, 완전 재현**: 비용이 GPT-4o mini 대비 약 200배. 현실적으로 불가.
- **B. GPT-4o mini 적용 실험** ← 채택: 비용 현실적, 방법론 효과 자체는 동일하게 검증 가능.
- **C. 실험 없이 논문 수치만 인용**: 보고서의 독창적 기여가 없어짐.

## Consequences

보고서에서 GPT-4o mini 결과와 논문 GPT-4 결과를 병렬 표로 제시할 때, 모델 차이가 성능 차이의 원인임을 명시해야 한다.
