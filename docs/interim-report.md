## 실험 개요

Yao et al. (2023) Tree of Thoughts 논문의 Game24 실험을 GPT-4 대신 GPT-4o mini에 적용.  
재현 실험이 아닌 **적용 실험** — 경량 모델에서의 성능 차이 확인이 목적.

|------|-----|
| 모델 | gpt-4o-mini (논문: GPT-4) |
| 태스크 | Game24 puzzles 900–999 (100개) |
| 온도 | 0.7 |
| ToT propose_prompt | 3-shot (논문 GPT-4: 1-shot, 논문 GPT-3.5: 3-shot) |

## 주요 발견

### 1. IO/CoT 기준선: 논문과 유사하거나 소폭 상회

gpt-4o-mini의 IO×1(13%)과 CoT×1(4%)은 논문 GPT-4 수치(7.3%, 4.0%)와 유사한 수준.  
단순 프롬프트에서는 모델 간 격차가 크지 않음.

### 2. ToT: 적용 가능하나 GPT-4 대비 성능 저하

3-shot propose_prompt 조정(ADR-0006) 후 실험 가능.  
b=5 기준 60% — 논문 GPT-4 b=5(74%)보다 14%p 낮음.  
b가 커질수록 성능 향상 추세(26→27→44→52→60%)는 논문과 동일하게 관찰됨.

**참고**: 논문 GPT-4는 1-shot propose_prompt, gpt-4o-mini는 3-shot 사용.  
따라서 직접 비교 시 조건 차이를 고려해야 함.

### 3. o4-mini: ToT 없이 76% — 가장 높은 성공률

단일 IO 프롬프트로 GPT-4 ToT b=5(74%)를 초과.  
내부 reasoning 만으로 외부 탐색 구조를 대체할 수 있음을 시사.  
비용: $0.71 / 100 puzzles (GPT-4o mini ToT b=5와 유사한 수준).
