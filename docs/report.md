## 3. 실험 설계

### 3.1 적용 모델 및 기본 조건

| 항목 | 본 실험 | 논문 원본 |
|------|---------|----------|
| 모델 | gpt-4o-mini | GPT-4 (Chat Completion) |
| 태스크 | Game24 puzzles 900–999 (100개) | Game24 puzzles 901–1000 (100개) |
| 온도 | 0.7 | 0.7 |
| 시스템 프롬프트 | 있음 (형식 강제) | 없음 |
| ToT propose_prompt | 3-shot | 1-shot |

### 3.2 논문 원본 조건과의 차이 및 이유

<!-- A+B 방식: why 중심으로 서술하되 기술 용어 병기
     - 시스템 프롬프트: GPT-4o mini가 markdown/LaTeX 형식으로 출력하는 경향이 있어,
       정해진 출력 형식을 따르도록 강제하는 시스템 프롬프트를 추가했다.
     - propose_prompt 3-shot: 1-shot 사용 시 모델이 연산 추적(left: ...)을 자주 생략해
       성공률 0%를 기록했다. 논문에서 GPT-3.5에도 동일한 이유로 3-shot을 사용했으며,
       GPT-4o mini에도 같은 조치를 적용했다. -->
